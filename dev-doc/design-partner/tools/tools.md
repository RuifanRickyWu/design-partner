# 工具

上级：[design-partner](../design-partner.md)
依赖：[聊](../talk/talk.md)

负责生成（图和视频）和评审两件工具性的事，被阶段调用，不跟人聊。

## 生成

### 什么时候用

- **出参考**：几个方向的整页氛围图，给人挑方向。按简报里的创造式主题和 build prompt 生成。
- **出素材**：页面里真正用的图和视频。

### 服务

- 走配置里定的服务。没有 API 的能力用 harness 自带的生图。
- harness 自带的生图要明确指示它用。它会用，但不指示就不会自己想起来。

### 拉开方向差异

- 直接让 AI "随机一点、独特一点"没用。它只会预测听起来随机的东西，出来还是同一套。
- 用种子字符串：让 AI 先用脚本生成一段长的随机字符串，从里面找子模式、特殊数字之类的灵感，推出配色、布局、字体等创作方向，再按方向生成。字符串不出现在成品里。出处是 Sakana AI 的 String Seed of Thought。
- 每个方向配一句话，说它怎么服务视觉动线。

### 图

- 页面里的视觉不要用代码画的渐变、几何形状、基础图案凑。那些一眼就是 AI 做的。
- 用真实生成的图片。需要的话配合 shader 或 3D 效果。

### 视频：循环动效素材

1. 在页面的背景色上渲染一段循环片段，比如 3D 物体或玻璃折射。先在背景色上渲染，折射和阴影才会带着背景的颜色。
2. 用视频抠像去掉背景。
3. 得到一段保留真实折射、焦散、阴影的素材，能叠在页面任何位置。

### 视频：状态转场

1. 不手写复杂的 CSS 或 GSAP 动画。
2. 生成起始帧和结束帧，让视频模型在两帧之间插值。
3. 把片段绑定到用户操作：随滚动逐帧播放，或在切换屏幕时触发。

### 验证

生成的东西都在浏览器里逐帧看，不只看代码。

### 产出

参考图存 `refs/`，每张带一句说明。素材图、动效素材、转场片段存 `assets/`。

## 评审

### 什么时候用

- 出稿循环的每一轮。
- 定稿做完减法和 AI 味审计之后，再调一次。
- 默认开，达标线 8 分。人可以说"不用评审"，或者改分数。

### 每轮怎么跑

1. 截图当前设计。
2. 在全新的上下文里调用评审。只给截图，不给代码、实现细节、之前的评语。
3. 评审做四件事：判断这个设计想走的美学方向；想象顶级设计工作室会怎么做这个方向；列出最大的差距；给一个 10 分制的分数。
4. 实现方拿评审意见改，再回到第 1 步。

### 给评审的要求

- 既看整体结构和构图，也看细节。
- 对过度、堆砌、一眼 AI 的模式扣分。
- 意见要具体，不要空话。
- 要大胆有主见，不选安全的。

### 评审 prompt 要点

- 角色：顶级工作室级别的设计总监。
- 只评美学、构图、节奏、打磨。不管代码。
- 识别设计意图，对照 Pentagram、Apple、Teenage Engineering 这类工作室做同一概念会是什么水平。
- 点出所有 AI 味。
- 列出最值得删除或简化的三处。
- 10 分制严格打分：7 分是普通 agency 水平，9 分是获奖级的手工品质。

### 规矩

- 达标线写在实现方的指令里，不写进评审的 prompt。
- 每轮用同一份评审 prompt。
- 评审用强模型，实现用便宜快的模型。
- 标准越具体越好。差："判断好不好看、像不像 AI"。可以："对照顶级工作室做法打分"。好："给 4 张专业作品加 1 张我们的截图，按完成度和品味排序"。
- 给评审参考图（moodboard、参考截图）当质量锚点。只做参考，不照抄。
- 先跑一两轮看收敛，不要无限循环。
