# 工具

两件工具性的事：生成（图和视频）、评审。被出参考、出稿、定稿调用，不跟用户聊。

## 生成

### 什么时候用

- **出参考**：几个方向的整页氛围图，给用户挑方向。按简报里的创造式主题和 build prompt 生成。
- **出素材**：页面里真正用的图和视频。

### 服务

走 `design-partner.env` 里配了 key 的服务。写一个小脚本读 env 文件、调接口、把结果存进 `refs/` 或 `assets/`。key 不出现在脚本以外的任何地方，不打印。

模型 ID 变得快。调用前查一下服务商当前的模型列表，不要把模型 ID 写死在页面里。

- **Gemini（nano banana）**：`GEMINI_API_KEY`。REST 走 `generativelanguage.googleapis.com` 的 `generateContent`，header 用 `x-goog-api-key`，`generationConfig.responseModalities` 里要带 `IMAGE`。图在返回的 `inlineData` 里，base64。
- **OpenAI（GPT Image）**：`OPENAI_API_KEY`。`POST https://api.openai.com/v1/images/generations`，body 给 `model`、`prompt`、`size`。图在返回的 `b64_json` 里。
- **fal.ai**：`FAL_KEY`。`POST https://queue.fal.run/<model-id>`，header `Authorization: Key <FAL_KEY>`，body 是模型自己的参数。异步：返回里有状态和结果的 URL，轮询到完成再取。图、视频、视频抠像、首尾帧生视频都在这里找模型。

没有 key 的能力：harness 自带生图工具的（Codex、Antigravity 一类），明确指示它用，它会用但不会自己想起来。都没有，先用代码画占位，并告诉用户这是占位。

### 拉开方向差异

- 直接让模型"随机一点、独特一点"没用。它只会预测听起来随机的东西，出来还是同一套。
- 用种子字符串：先用脚本生成一段长的随机字符串，从里面找子模式、特殊数字之类的灵感，推出配色、布局、字体等创作方向，再按方向生成。字符串不出现在成品里。出处是 Sakana AI 的 String Seed of Thought。
- 每个方向配一句话，说它怎么服务视觉动线。

### 图

- 页面里的视觉不要用代码画的渐变、几何形状、基础图案凑。那些一眼就是 AI 做的。
- 用真实生成的图片。需要的话配合 shader 或 3D 效果。

### 视频：循环动效素材

1. 在页面的背景色上渲染一段循环片段，比如 3D 物体或玻璃折射。先在背景色上渲染，折射和阴影才会带着背景的颜色。
2. 用视频抠像去掉背景。
3. 得到一段保留真实折射、焦散、阴影的素材，能叠在页面任何位置。

### 视频：状态转场

1. 不手写复杂的 CSS 或 GSAP 动画。
2. 生成起始帧和结束帧，用支持首尾帧的视频模型在两帧之间插值。
3. 把片段绑定到用户操作：随滚动逐帧播放，或在切换屏幕时触发。

### 验证

生成的东西都在浏览器里逐帧看，不只看代码。

### 产出

参考图存 `refs/`，文件名带方向编号，每张在简报外另附一句说明。素材图、动效素材、转场片段存 `assets/`。

## 评审

### 什么时候用

- 出稿循环的每一轮。
- 定稿做完减法和 AI 味审计之后，再调一次。
- 默认开，达标线 8 分。用户可以说"不用评审"，或者改分数。

### 每轮怎么跑

1. 截图当前设计。
2. 在全新的上下文里调用评审（子代理）。只给截图，不给代码、实现细节、之前的评语。
3. 评审做四件事：判断这个设计想走的美学方向；想象顶级设计工作室会怎么做这个方向；列出最大的差距；给一个 10 分制的分数。
4. 你拿评审意见改，再回到第 1 步。

### 评审 prompt

每轮用同一份。达标线不写进去。

```
You are a design director at a top-tier studio, reviewing one screenshot of a web page.

Judge only what you see: aesthetics, composition, rhythm, polish. Ignore code and implementation.

1. Name the aesthetic direction this design is going for.
2. Describe how a studio like Pentagram, Apple, or Teenage Engineering would execute that same direction.
3. List the biggest gaps between this screenshot and that execution. Look at overall structure and composition first, then details. Be specific; no vague prose.
4. Call out every pattern that reads as generated by default: ambient purple or cyan glow, gradient borders, everything boxed in rounded cards, uniform pill shapes, decorative badges with no function, the text-left graphic-right hero.
5. Name the three highest-leverage things to delete or simplify.
6. Score it out of 10. Be strict: 7 is competent agency work, 9 is award-level craft.

Be bold and opinionated. Do not reward safe choices.
```

### 规矩

- 达标线写在你自己的指令里，不写进评审的 prompt。
- 每轮用同一份评审 prompt。
- 评审用强模型，实现用便宜快的模型。
- 标准越具体越好。差："判断好不好看、像不像 AI"。可以："对照顶级工作室做法打分"。好："给 4 张专业作品加 1 张我们的截图，按完成度和品味排序"。手里有参考图时，用最后这种。
- 给评审参考图（moodboard、参考截图）当质量锚点。只做参考，不照抄。
- 先跑一两轮看收敛，不要无限循环。两轮分数没涨，停下来问用户。
